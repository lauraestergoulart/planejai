## Melhoria implementada

Implementei o Desafio 1 do projeto original: a página de Histórico de Simulações.

- Lista todas as simulações salvas, ordenadas da mais recente para a mais antiga
- Permite excluir uma simulação (com confirmação antes de apagar)
- Ao clicar em "Ver detalhes", navega para o resultado já salvo, sem chamar a IA novamente
- Estado vazio quando não há nenhuma simulação salva ainda
